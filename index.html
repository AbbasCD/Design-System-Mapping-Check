How matches were decided

Colours: an identical hex in the CD palette is a Match when CD has a semantic (Mapped) token for that use (bg/surface for fills, text for text, border for strokes). A Fixed-only hex, any colour with opacity, or the nearest CD colour within ΔE 10 is Approximate. Anything further is No match. ΔE (CIE76) guide: under 2 barely visible, 2–5 close, 5–10 noticeable.

Text: Match only when font, weight, size and line height equal a CD text style. Same font and size but a different weight or line height (including "auto") is Approximate. Inter, or sizes outside CD's font-size scale (e.g. 11, 13, 15), are No match.

Radius / stroke width / gap / padding: equal to a CD Fixed token is a Match. Equal only to a responsive token at one breakpoint, or within 2px (0.5px for strokes) of a Fixed token, is Approximate. Otherwise No match.
